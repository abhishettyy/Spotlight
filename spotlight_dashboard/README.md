# Spotlight - Event Management Through Motion

Spotlight is a premium, modern web application designed for university clubs and organizations to discover, register for, and manage live events. Built with a high-fidelity glassmorphism aesthetic and buttery-smooth animations, Spotlight makes event ticketing and payment verification a seamless experience.

## Features

- **Liquid Event Creation**: Craft events with a fluid step-by-step builder. From concept to live in under two minutes.
- **Payment Moderation**: Built-in support for both free and paid events. Integrates QR-based payment verification with manual approval pipelines.
- **Smart Publishing**: Free events go live instantly, while paid events enter an intelligent moderation stream automatically.
- **Dynamic Dashboard**: A comprehensive admin overview with quick actions, real-time KPI counters, and interactive event data.

## Tech Stack

- **Framework**: React + Vite
- **Styling**: Tailwind CSS + Custom CSS Modules (Glassmorphism UI)
- **Animations**: Framer Motion (`motion/react`)
- **Icons**: Lucide React

## Getting Started

1. **Install dependencies**:
   ```bash
   npm install
   ```
2. **Start the development server**:
   ```bash
   npm run dev
   ```
3. Open your browser to the local URL provided in the terminal (usually `http://localhost:5173/`).

## Project Structure
- `src/app/App.tsx`: Main application entry point containing all routing, dashboard views, and core components.
- `src/index.css`: Core design system tokens and Tailwind directives.
